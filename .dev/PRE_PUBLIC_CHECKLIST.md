# Pre-public checklist

Run through this before flipping the repository from private to public.

## Remove development-only material

- [ ] `git rm -r .dev/` — this whole directory, including this file
- [ ] `git rm -r .claude/` if it was committed for cross-machine settings
- [ ] Remove any `TODO`/`FIXME` left as a note-to-self rather than a real code marker

## Scan for traces

```bash
grep -rniE 'claude|anthropic|copilot|chatgpt|AI-generated|generated by|Co-Authored-By|🤖' \
  --exclude-dir=.git --exclude-dir=node_modules --exclude-dir=.venv .

git log --format='%s%n%b' | grep -niE 'claude|anthropic|Co-Authored-By|🤖'
```

Both must come back empty. The second should already be empty by construction — commit messages
have been kept clean from the first commit precisely so that no history rewrite is ever needed.

## Scan for leaked local detail

- [ ] No absolute paths from a dev machine (`/home/administrator`, `C:/Users/...`) in code, docs,
      config or test fixtures
- [ ] No personal email or account names outside the git author field
- [ ] No hardcoded dataset paths pointing at sibling projects

```bash
grep -rn '/home/administrator\|C:/Users\|C:\\\\Users' \
  --exclude-dir=.git --exclude-dir=node_modules --exclude-dir=.venv .
```

## Confirm nothing sensitive was ever committed

- [ ] No `.env`
- [ ] No `*.db` project files
- [ ] No dataset images
- [ ] `git log --stat --all -- '*.db' '*.env' '*.jpg' '*.png'` returns nothing unexpected
      (icons under `packaging/` are fine)

## Final polish

- [ ] Add a LICENSE
- [ ] README reads as a public project: what it is, screenshots, install, build from source, the
      SmartScreen note
- [ ] `CLAUDE.md` — decide whether it stays (it is genuinely useful project documentation) or is
      folded into `CONTRIBUTING.md`
- [ ] CI is green on a clean clone
- [ ] A tagged release with a downloadable Windows zip exists
- [ ] Flip visibility
